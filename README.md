# 🌍 منصة تعلم اللغات - Language Learning Platform

موقع تعليمي متكامل لتعلم 8 لغات مختلفة بطرق تفاعلية وممتعة.

## ✨ المميزات

- ✅ 8 لغات متاحة (العربية، الإنجليزية، الفرنسية، الألمانية، الإسبانية، الإيطالية، الصينية، اليابانية)
- ✅ 26 درس شامل
- ✅ 20+ كلمة مع الترجمة والنطق والأمثلة
- ✅ تمارين تفاعلية لتكوين الجمل
- ✅ اختبارات قياس التقدم
- ✅ نظام تسجيل وتسجيل دخول آمن
- ✅ تتبع تقدم المستخدم

## 🚀 التشغيل المحلي

### المتطلبات
- Python 3.7+
- pip

### الخطوات

1. **استنساخ المستودع** (أو تنزيل الملفات)
```bash
git clone <repository-url>
cd اللغات
```

2. **تثبيت المكتبات**
```bash
pip install -r requirements.txt
```

3. **تشغيل السيرفر**
```bash
python app.py
```

4. **فتح الموقع**
افتح المتصفح وذهب إلى: `http://localhost:5000`

## 🌐 النشر على Render

### خطوات النشر

1. **رفع المشروع إلى GitHub**
   - أنشئ مستودع جديد على GitHub
   - رفع جميع الملفات بما فيها `Procfile` و `requirements.txt`

2. **التسجيل على Render**
   - اذهب إلى https://render.com
   - سجل دخول أو أنشئ حساب

3. **إنشاء Web Service**
   - انقر على "New" ثم "Web Service"
   - اختر المستودع الخاص بك على GitHub
   - أكمل الخطوات

4. **الإعدادات**
   - اسم التطبيق: أي اسم تريده
   - البيئة: Python 3
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python app.py`

5. **انتظر التثبيت**
   - Render سيثبت المكتبات وينشر السيرفر
   - ستحصل على رابط مثل: `https://your-app-name.onrender.com`

## 📱 كيفية الاستخدام

1. **إنشاء حساب جديد** - املأ النموذج وأنشئ حسابك
2. **تسجيل الدخول** - ادخل بريدك وكلمة المرور

4. **ابدأ الدروس** - اتعلم الدروس والكلمات
5. **اختبر نفسك** - حل التمارين والاختبارات

## 📊 قاعدة البيانات

المنصة تستخدم SQLite مع الجداول التالية:
- `users` - المستخدمين
- `languages` - اللغات المتاحة
- `lessons` - الدروس
- `vocabulary` - المفردات
- `exercises` - التمارين
- `quiz_questions` - أسئلة الاختبارات
- `user_progress` - تقدم المستخدم
- `exercise_results` - نتائج التمارين
- `quiz_results` - نتائج الاختبارات
